A track's audio, for playing and for downloading.
Listeners reach published tracks of published albums; editors every track that is not deleted.
`404 Not Found` when the track does not exist, the caller may not reach it, or its file is missing.

[[audio]]
== Audio

The audio file as it was uploaded, for the web player.
It honours `Range` requests, so the player can seek.
