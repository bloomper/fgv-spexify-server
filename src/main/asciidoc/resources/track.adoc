A track's audio, for playing and for downloading.
Listeners reach published tracks of published albums; editors every track that is not deleted.
`404 Not Found` when the track does not exist, the caller may not reach it, or its file is missing.

[[audio]]
== Audio

The audio file as it was uploaded, for the web player.
It honours `Range` requests, so the player can seek.

operation::track-audio-get[snippets='security,path-parameters,request-headers,http-request,response-headers']

[[download]]
== Download

The same file as an attachment, named by the track's number and title.

operation::track-download-get[snippets='security,path-parameters,request-headers,http-request,response-headers']

[[link]]
== Signed links

The web's player and downloads fetch audio from the API's public address, with no access token: the web asks for a signed link with the user's token and hands it to the browser.
`/api/tracks/{id}/download/link` does the same for a download.
A link opens that one file, until it expires.

operation::track-audio-link-get[snippets='security,path-parameters,request-headers,http-request,http-response,response-fields']

The link then serves the file as above, `Range` requests included.
A link whose signature does not match is answered `403 Forbidden`, and an expired one `410 Gone`.
