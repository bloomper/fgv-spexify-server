[[introduction]]
== Introduction

Spexify Server is the backend of Spexify, FGV's music service for the songs the spex have recorded over the years.

The purpose of this documentation is to provide details on how to develop within Spexify Server and how to integrate Spexify Server into another application, e.g. a web application or a Subsonic app.
